## 换电脑继续

在已有仓库的根目录先运行 `git status`，确认没有与远端冲突的未提交修改，再运行：

```bash
git pull --ff-only
```

新电脑尚无仓库时：

```bash
git clone https://github.com/PH1439929991/agent-learning.git
cd agent-learning
```

没有虚拟环境才创建，已有环境不用重复覆盖：

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
```

虚拟环境不能直接跨电脑复制；环境一致不仅要 .env，还要 Python、依赖和代码版本一致。离线练习不需要配置密钥。

回家先打开 [第十八节学习文档](18-把检索接成Agent工具.md) 的第 7 部分，看真实请求和结果，再运行本节的两个离线测试文件：

```bash
PYTHONPATH=src .venv/bin/python -m pytest src/agent_learning/module_08_rag/test_rag_search_tool.py src/agent_learning/module_08_rag/test_rag_agent_live.py -q
```

预期 27 个通过，不需要密钥、索引或真实接口。可自行练习把测试里的正常资料改为空结果，观察 tool 消息如何变化；不要修改原始资料库来做这个练习，以免使已有向量索引失效。

第十节已在家写好的代码请保留，不用重做。若 git pull 提示冲突或无法快进，停止并保留现场，不要强制覆盖本地修改。其余第八章回归测试：

```bash
PYTHONPATH=src .venv/bin/python -m pytest src/agent_learning/module_08_rag --ignore=src/agent_learning/module_08_rag/test_checked_rag_answer.py -q
```

第八章排除旧第十节后共 140 个测试通过；连同第五章共 150 个。第十节旧 TODO 不计入当前验收。
