# 第九节：引用编号校验

代码：[citation_checks.py](../../src/agent_learning/module_08_rag/citation_checks.py)

## 检查什么

check_citations(answer, source_count) 检查答案引用的数字是否在 1 到 source_count 内。

示例 ("编号越界", "回答。[3]", 2) 最后的 2 是实际提供的资料条数，不是回答引用次数。只提供两段，只能引用 [1] 和 [2]。

真实流程用最终发送的 len(hits)，不是片段中的字段数、全库大小或请求的 top_k。检索三段但最终发送两段，应重新编号后按两段检查。

## 已完成实现

```python
cited_numbers = extract_citation_numbers(answer)
invalid_numbers = [
    number for number in cited_numbers
    if number < 1 or number > source_count
]
```

提取函数识别半角数字引用，去重排序。输入 [2][1][2] 得到 [1, 2]；只支持无前导零的 [1] 格式，不支持 [1,2]、[来源1]、[01]。

返回四个字段：

- cited_numbers：出现的引用编号。
- invalid_numbers：越界编号。
- has_citations：bool(cited_numbers)。
- references_valid：bool(cited_numbers) and not invalid_numbers。

## 判断例子

| 提供条数 | 回答引用 | 越界编号 | references_valid |
| --- | --- | --- | --- |
| 2 | [1][2] | [] | True |
| 2 | [1][3] | [3] | False |
| 2 | 没有引用 | [] | False |
| 0 | [1] | [1] | False |

没有引用不一定回答错，合理拒答可以没有引用；编号存在也不证明资料支持答案。比如资料写喜欢阅读，回答喜欢游泳。[1] 仍会通过编号检查。
