# 第七节：索引保存与复用

代码：[index_persistence.py](../../src/agent_learning/module_08_rag/index_persistence.py)

## 为什么要保存

资料不变时，不必每次问题都重新给所有片段计算向量。保存后查询只编码新问题，资料向量从磁盘读取。

避免重复计算靠的是代码分支，而不是 JSON 自动缓存：

- 建库：切片 → 全部片段 Embedding → 保存。
- 查询：加载 → 校验缓存 → 问题 Embedding → 本地排序。
- 查询不调用 build_vector_index；缓存失效时直接报错，不自动付费重建。

## 文件格式

```python
{
    "version": 1,
    "model": "建库模型",
    "base_url": "建库服务地址",
    "source_hash": "切分结果的指纹",
    "chunks": [
        # 每段保留 chunk_id、document_id、text、metadata、embedding
    ],
}
```

既保存向量，也保存正文和来源；最终生成答案需要的是正文。API Key 不在缓存中。

## Python 文件读写

```python
with path.open("x", encoding="utf-8") as file:
    json.dump(payload, file, ensure_ascii=False, indent=2, allow_nan=False)

with path.open("r", encoding="utf-8") as file:
    return json.load(file)
```

x 只创建新文件，已存在就报错；r 读取；w 写入但会截断已有文件；a 追加。with 结束后自动关闭文件。

dump/load 面向文件，dumps/loads 面向字符串。json.load 恢复 Python 字典，并不调用模型。

validate_index 检查模型、服务、资料指纹、片段和向量结构；指纹不是事实认证。同名模型权重变化仍可能需要重建。
