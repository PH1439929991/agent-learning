## 1. 输入是什么

cases 是列表，每个字典代表一道题：

```python
cases = [
    {
        "case_id": "q1",
        "query": "练习角色住在哪里，喜欢什么？",
        "expected_chunk_ids": ["A", "B"],
        "retrieved_chunk_ids": ["C", "A", "D"],
    },
    # 第二题、第三题……
]
```

case_id 用来定位题目；query 是问题，仅用于展示；另外两个列表是人工标注的相关片段和检索器返回的排名。单题函数不使用 query 生成检索结果，汇总函数也不执行搜索。

## 2. 三道题怎样汇总

示例数据 k=3 时：

| 题目 | 预期片段 | 检索前 3 条 | Hit@3 | Recall@3 |
| --- | --- | --- | --- | --- |
| q1 | A、B | C、A、D | True | 0.5 |
| q2 | C | A、B、D | False | 0.0 |
| q3 | D | D、A、B | True | 1.0 |

```text
hit_count = 2
recall_sum = 0.5 + 0.0 + 1.0 = 1.5
case_count = 3

hit_rate_at_k = 2 / 3，约 0.6667
mean_recall_at_k = 1.5 / 3 = 0.5
```

单题 Hit@K 是布尔值，整组 Hit rate@K 是命中问题的比例。不要把命中的片段总数当成 hit_count：一道题即使命中五段，也只给命中题数加 1。

平均召回率先算每道题，再取平均，每道题权重相同。例如第一题有 1 个相关片段且全部找回，第二题有 3 个相关片段但全部未找回，平均召回率是 (1+0)/2=0.5，不是把片段合并计算的 1/4。

## 4. 边界规则

- 空 cases 报错，避免除以零；不能把“没测任何题”报告成满分。
- K 必须是正整数，不能是 True。
- 某题没有预期相关片段时沿用单题异常，不悄悄跳过，也不计为零分。
- 有预期片段但检索结果为空，是正常失败案例，计入统计。
- 返回 0～1 的数值，不乘 100、不转成百分比字符串，也不提前四舍五入。
